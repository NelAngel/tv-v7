# LYGANE Smart TV 3.0
El launcher muestra `app/src/main/assets/launcher.html` en un WebView: lo que ves en
`preview/lygane-tv-launcher.html` (abrelo en el navegador, usa las flechas) es EXACTAMENTE lo que sale en la TV.
Las apps de la lista son las reales instaladas en la TV (con sus iconos).
Para cambiar el diseño edita solo `launcher.html` (y copia el cambio a assets/).
